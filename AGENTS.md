# Project instructions

Read README.md, docs/STATUS.md, and the active specification before changes.
Keep all source and commit metadata free of personal information. Never copy conversation transcripts into this repository.
No credentials, raw real captures, local databases, watchlists, screenshots, or traces in Git.
No paid services, public deployment, or silent live crawling. Network access must follow the execution environment's policy.
Preserve explicit unknown values, evidence provenance, immutable observations, and reversible decisions.
Synthetic tests are not proof of live retailer accuracy. Report blocked checks as blocked.
Run npm test, npm run benchmark, and npm run privacy before claiming a milestone is verified.
